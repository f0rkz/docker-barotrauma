# Security policy

## Supported versions

Security updates are provided for the latest published major version.

## Reporting a vulnerability

Please report vulnerabilities privately through GitHub's security advisory feature:

https://github.com/f0rkz/docker-barotrauma/security/advisories/new

Do not open a public issue for an undisclosed vulnerability. Include affected image
tags, reproduction steps, and any known mitigations in the report.
